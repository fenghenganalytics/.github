# FengHeng Analytics

**Air quality intelligence for under-resourced cities.**

We build the data infrastructure that lets city governments in West Africa see, trust, and act on their own air quality data — sensor ingestion, satellite fusion, quality control, and public dashboards.

## What we do

- **AQDI (Air Quality Data Infrastructure)** — end-to-end pipeline: ground sensor networks → QC engine → analytics → public-facing dashboards
- **Satellite fusion** — CAMS aerosol/dust, ERA5 meteorology, FIRMS/GFAS fire emissions combined with ground truth
- **QC-first methodology** — every reading screened for optical saturation, sensor flatlines, calibration inversion, and zero-drift before it informs public information ([methodology](https://github.com/fenghenganalytics/aqdi-methodology))
- **Public transparency dashboards** — citizens see what the city sees
